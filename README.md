# Shinobi RPG 3D

Protótipo de RPG de ação 3D inspirado no ritmo e na câmera de arena fighters de anime.

> Projeto independente/fan prototype. Não inclui assets, áudio ou código proprietários de Naruto/Storm.

## Engine
Godot 4.x

## Primeira meta jogável
- movimentação 3D responsiva
- câmera em terceira pessoa
- corrida e pulo
- dash
- base para lock-on, chakra, combos, substituição e jutsus

## Controles
- WASD: mover
- Mouse: câmera
- Espaço: pular
- Shift: dash/correr

## Executar
Abra a pasta na Godot 4.x e rode `main.tscn`.
